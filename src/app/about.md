# App

Owns shared session state, responsive sidebar and profile navigation, protected placeholder routes, account and login forms, and browser presentation.

The standalone `/next-rep` landing page renders outside the app layout and session
provider. Its decorative SVG ribbon rotates a depth-separated loop before applying
tension, with fine overlapping sections and continuous shading. It spans the screen and relaxes
into a gently sagging band when Get started comes into view, with a static
released ribbon for reduced motion.
